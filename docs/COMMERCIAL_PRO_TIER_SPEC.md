## 💎 2. Pro 버전의 5대 핵심 셀링 포인트 (Key Selling Points)

1. **⚡ C++ 네이티브 커널 하드웨어 가속 (`PurifyEngineCore.dll`)**:
   - Win32 `FindFirstFileExW`, RestartManager 락 헌터, VSS 네이티브 API 호출로 **최대 10배 빠른 초고속 정화**.
2. **🛡️ 무제한 세이프포인트 복구 (Safepoint Snapshot & Rollback)**:
   - 정화 작업 직전의 레지스트리 및 시스템 상태를 안전하게 저장하여, 문제 발생 시 1-Click으로 이전 상태 복원.
3. **⏰ 무음 헤드리스 스케줄러 (Silent Headless Scheduler)**:
   - 부팅 초기 과부하 방지를 위한 **지연 실행(0~15분)** 및 **N시간 주기 무음 백그라운드 정제**.
4. **🧠 지능형 트레이 메모리 자동 정제**:
   - 시스템 트레이 백그라운드 상주 중, RAM 사용량이 지정한 임계값(예: 80%)을 넘으면 작업 방해 없이 즉시 압축.
5. **📡 Central Commander LAN 원격 플릿 관제 (Enterprise 전용)**:
   - 동일 네트워크(LAN) 내 모든 Windows PC를 UDP 브로드캐스트로 자동 탐색하여 중앙 콘솔에서 원격 일괄 최적화.

## 🔐 3. 라이선스 검증 메커니즘 (License Key Verification)

1. **라이선스 키 포맷**:
   - `PURIFY-PRO-XXXX-YYYY-ZZZZ-WWWW` (20자리 알파벳/숫자 조합)
2. **오프라인 HWID 오프라인 암호화 인증**:
   - 메인보드 UUID + CPU ID + MAC 주소 조합의 SHA-256 해시값으로 라이선스 생성.
   - **폐쇄망/보안구역 PC**에서도 인터넷 연결 없이 오프라인 키로 즉시 Pro 인증 가능.
3. **앱 내 인증 다이얼로그 (`LicenseService.cs` & `index.tsx`)**:
   - 상단 **[라이선스]** 버튼 클릭 시 키 입력 다이얼로그 가동.
   - 키 인증 성공 시 UI 상단 뱃지가 **`v4.43.0 Pro Licensed`**로 즉각 변경되며 모든 락 해제.
