Official Release v4.63.0

WinPurify Pro v4.63.0

글로벌 뮤텍스 제거 기반 다중 인스턴스 & Central Commander 동시 실행 완벽 지원 및 메인 창 렌더링 안정화 솔루션

📌 1. 프로그램 소개 (Body)

WinPurify Pro는 단일 PC 시스템 최적화부터 다중 PC 중앙 관제(Central Commander)까지 완벽하게 지원하는 차세대 Windows 11/10 전용 시스템 정화 솔루션입니다.

최신 v4.63.0에서는 기존 전역 애플리케이션 레벨 Mutex 락킹 방식을 전면 개편하여, 단일 PC 내에서 WinPurify Pro 다중 인스턴스와 Central Commander가 서로 차단되지 않고 완벽하게 동시 실행될 수 있도록 자율적인 프로세스 고유 식별자(PID + GUID 기반) 체계를 도입하였습니다. 아울러 트레이 아이콘 ID 동적 할당 및 메인 창 Visible 상태 보장, XAML 리소스 사전 등록을 완료하였습니다.

🚀 2. v4.63.0 최신 업데이트 하이라이트 (Updates)

  • ⚡ 글로벌 Mutex 제거 및 다중 인스턴스 동시 실행 허용: 기존 인스턴스 강제 종료를 유발하던 전역 뮤텍스를 제거하고 프로세스별 독립 식별자(`ProcessInstanceId`)를 부여하여 동시 실행 보장.
  • 🛡️ WinPurify Pro & Central Commander 완전 공존: 단일 PC 환경에서 최적화 모듈과 중앙 관제 콘솔이 충돌 없이 나란히 구동 가능.
  • 🔔 독립 트레이 아이콘 UID 격리: 프로세스 ID 하위 비트 기반 동적 `uID` 할당으로 인스턴스 간 트레이 알림 덮어쓰기 방지.
  • 🚀 시작 시퀀스 최적화 및 Visible 절대 보장: C++ 네이티브 엔진 비동기 예열과 메인 창 명시적 Visible 설정 및 디스패처 워치독으로 고스트 윈도우 원천 차단.
  • 🛠️ XAML 리소스(WindowDropShadow & InverseBoolConverter) 완벽 해결: XAML 파서 런타임 예외를 원천 차단하는 전역 리소스 사전 등록 및 동기화.
